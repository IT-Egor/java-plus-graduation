# Дипломный проект `Explore with me` (микросервисная архитектура)

**Веб-приложение для публикации и поиска событий.**  
Платформа позволяет пользователям публиковать события, находить интересные мероприятия и участвовать в них.

Template repository для проекта Graduation.

## 🎯 Цель проекта
- Декомпозиция монолитной архитектуры проекта на микросервисы
- Изучение основ разработки рекомендательных систем
- Закрепление полученных знаний

## 📋 Функциональность
[Старая функциональность](https://github.com/IT-Egor/java-explore-with-me-plus/blob/main/README.md#-функциональность) проекта не изменилась.  
Новая:
- Отслеживание действий пользователей (просмотры, регистрации, лайки)
- Сбор статистики взаимодействий с событиями
- Взвешивание действий по степени вовлеченности
- Формирование рекомендаций событий для каждого пользователя
- Поиск событий, похожих на интересующие пользователя

## ⚙️ Технологический стек
- **Язык:** Java 21
- **Фреймворки:** Spring Boot
- **Архитектура:** Микросервисы (Spring Cloud)
- **Межсервисное взаимодействие:** REST API, gRPC, Apache Kafka
- **Базы данных:** PostgreSQL
- **Доступ к данным:** Spring Data JPA, Hibernate
- **Сериализация:** JSON, Avro, Protocol Buffers
- **Конфигурация:** Spring Cloud Config
- **Обнаружение сервисов:** Eureka
- **API шлюз:** Spring Cloud Gateway
- **Circuit Breaker:** Resilience4J
- **Контейнеризация:** Docker
- **Сборка:** Maven
- **Тестирование:** Postman
- **Документация API:** OpenAPI

## 🏗️ Архитектура и ключевые компоненты

### Микросервисная архитектура

Для удобства приложение разбито на несколько ключевых модулей:

| Модуль                     | Сервис             | Назначение                                       |
|----------------------------|--------------------|--------------------------------------------------|
| **Ядро (Core)**            | Comment Service    | Управление комментариями к событиям              |
|                            | Event Service      | Управление событиями, категориями и подборками   |
|                            | Request Service    | Управление запросами на участие в событиях       |
|                            | User Service       | Управление пользователями                        |
| **Инфраструктура (Infra)** | Config Server      | Централизованное управление конфигурациями       |
|                            | Discovery Server   | Регистрация и обнаружение сервисов               |
|                            | Gateway            | Единая точка входа и маршрутизация запросов      |
| **Статистика (Stats)**     | Collector Service  | Сбор данных о действиях пользователей через gRPC |
|                            | Aggregator Service | Агрегация и обработка потоковых данных из Kafka  |
|                            | Analyzer Service   | Анализ данных и формирование рекомендаций        |

### Старые сервисы
На основе [модели данных из этого проекта на монолитной архитектуре](https://github.com/IT-Egor/java-explore-with-me-plus/blob/main/README.md#модель-данных) были выделены следующие микросервисы:

1. Сервис комментариев (Comment Service)
2. Сервис событий (Event Service)
3. Сервис заявок (Request Service)
4. Сервис пользователей (User Service)

Подробно с их функциональностью можно ознакомиться [здесь](https://github.com/IT-Egor/java-explore-with-me-plus/blob/main/README.md#основные-сервисы)

### Новые сервисы

#### 5. **Сервис сбора данных (Collector Service)**
- Приём данных о пользовательских действиях (просмотры, регистрации, лайки) через gRPC
- Отправка подготовленных событий в Kafka для дальнейшего анализа

#### 6. **Сервис агрегации данных (Aggregator Service)**
- Обработка и агрегация потоковых данных из Kafka в реальном времени
- Подготовка структурированных данных для анализа и рекомендаций
- Отправка агрегированных данных в Analyzer Service через Kafka

#### 7. **Сервис анализа и рекомендаций (Analyzer Service)**
- Анализ агрегированных данных пользовательского поведения
- Расчёт коэффициентов схожести между событиями на основе действий пользователей
- Формирование персонализированных рекомендаций с использованием алгоритмов коллаборативной фильтрации
- Предоставление API рекомендаций через gRPC для других сервисов системы
